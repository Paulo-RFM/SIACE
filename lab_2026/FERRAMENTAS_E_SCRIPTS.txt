SIACE - FERRAMENTAS E SCRIPTS USADOS
====================================
Inventário de 22/11/2026. Caminhos relativos a lab_2026/. As dependências Python com versão estão em
requirements.txt (projeto) e docker/requirements.txt (contêiner de inferência).
As descrições dos scripts foram tiradas da documentação de cada arquivo. Os scripts sem documentação
estão listados à parte, sem descrição.


1. HARDWARE E SISTEMA
---------------------
- CPU Intel Core i5-4430 (3,0 GHz), 30 GB de RAM
- GPU NVIDIA GeForce GTX 1050 Ti, 4 GB; driver 535.183.01; CUDA 12.1 (build do PyTorch)
- Ubuntu 20.04.6 LTS
- Anaconda, com dois ambientes:
    siace : Python 3.10.19, PyTorch 2.5.1 (treino, avaliação, inferência, figuras)
    geo   : Python 3.10, GDAL 3.6.2, matplotlib (recorte e reprojeção de rasters, mapas)


2. BIBLIOTECAS PRINCIPAIS (versões em requirements.txt)
-------------------------------------------------------
- PyTorch / torchvision ............ treino e inferência das redes
- segmentation-models-pytorch ...... U-Net, U-Net++, DeepLabV3+ e SegFormer (codificadores ResNet-34 e MiT-B1)
- timm ............................. codificadores usados pelo segmentation-models-pytorch
- efficientnet-pytorch ............. classificador de espécies EfficientNet-B0
- scikit-learn ..................... métricas, divisões e relatórios de classificação
- scikit-image / SciPy ............. Watershed, h-maxima, transformada de distância, morfologia
- OpenCV ........................... contornos, máscaras e operações de imagem
- NumPy / pandas ................... dados e tabelas
- Pillow ........................... leitura de tiles e das tags GeoTIFF
- Shapely / pyproj ................. geometria das copas, união entre tiles e projeções (SIRGAS 2000 / UTM)
- GDAL 3.6.2 (osgeo) ............... recorte em tiles, reprojeção, rasterização, GeoPackage
- rasterio / geopandas ............. leitura de rasters e vetores em scripts auxiliares
- matplotlib / seaborn ............. gráficos e mapas
- requests ......................... API 0.6 do OpenStreetMap (servidor de testes)
- tqdm / psutil .................... progresso e memória


3. OUTRAS FERRAMENTAS E SERVIÇOS
--------------------------------
- LabelMe .......................... anotação manual dos polígonos de copa e espécie (fonte dos rótulos,
                                     conforme build_species_manifest.py)
- QGIS ............................. conferência visual das árvores, das copas e do georreferenciamento
- Google Earth ..................... desenho do polígono KML da área urbana de João Pessoa
- OpenStreetMap, API 0.6 ........... envio de árvores, só no servidor de testes
                                     (master.apis.dev.openstreetmap.org)
- Docker ........................... contêiner de inferência (docker/); a imagem ainda não foi construída
- Git / GitHub ..................... versionamento (github.com/Paulo-RFM/SIACE, ramo siace-publicacao)
- Overleaf / LaTeX (abnTeX2) ....... redação da monografia (não versionada no GitHub)


4. MODELOS E PARÂMETROS DO SISTEMA (incluídos no ramo siace-publicacao)
----------------------------------------------------------------------
- runs/arq_segformer_mit_b1_20261110/   SegFormer MiT-B1, 3,19 cm (modelo do sistema), limiar 0,40
- runs/res_segformer_8cm_20261121/      SegFormer MiT-B1, imagens degradadas para 8 cm (variante), limiar 0,50

5. SCRIPTS DO SISTEMA FINAL (inferência)
----------------------------------------
pipeline_cidade.py ................. tile -> segmentação -> individualização -> EfficientNet-B0 -> árvore
                                     georreferenciada (GeoJSON/CSV)
separate_tree_crowns_whatershed.py . separa as copas individuais a partir da máscara binária (Watershed / h-maxima)
tree_georef.py ..................... georreferencia as copas pelas tags GeoTIFF e une as partes cortadas entre tiles
species_data.py .................... regras de dados da classificação de espécies (split espacial, recortes, classes)
docker/siace.sh .................... entrada do contêiner: ortomosaico -> tiles -> pipeline (--modelo 3cm|8cm)
docker/preparar_ortomosaico.py ..... reprojeta um ortomosaico RGB para a grade de 3,19 cm (EPSG:4326) e recorta
docker/slicer.py ................... recorte em tiles de 512 x 512 px, sem sobreposição, bordas brancas, com GDAL
docker/baixar_modelos.sh ........... baixa ou confere (SHA-256) os pesos dos modelos
docker/Dockerfile .................. imagem com GDAL 3.6.2 e PyTorch 2.5.1


6. SCRIPTS DE TREINO
--------------------
tree_segmentation_arquiteturas.py .. treino das arquiteturas de segmentação (SegFormer, U-Net++, DeepLabV3+),
                                     cópia do script da U-Net principal com a arquitetura como parâmetro
tree_segmentation_resnet_26_512softAug4.py
                                     treino da U-Net ResNet-34 (modelo experimentado de referência)
aligned_augmentation.py ............ augmentation geométrica sincronizada entre imagem e máscara (correção de 06/11)
train_species_efficientnet.py ...... treino auditável do classificador de espécies EfficientNet-B0
run_classification_suite.py ........ orquestra os treinos de classificação de espécies
run_binary_species_suite.py ........ classificadores binários "uma espécie contra as demais"
build_species_manifest.py .......... manifesto auditável dos recortes de espécies a partir das anotações LabelMe
augment_rare_species.py ............ balanceamento por aumento offline, só no treino do split espacial
degradar_resolucao.py .............. simula imagens de 8 cm e 15 cm a partir dos tiles anotados de 3,19 cm
